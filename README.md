# IU-Indianapolis-HRC

Repository for storing various scripts and resources for use
in the HRC. Each 'project' will have it's own folder with all
the needed information inside.

I sugest cloning the repository in one location, and then
you will have access to all the tools and scripts that are
contained herein. However, each script can be downloaded
separately if you do not wish the clone the repository.

Any program issues (that is, the script itself produced and error)
can be added to the Github Issues tab for this repo. If the issue
is something about what you are doing or you need help running the code,
first please consult the docs attached to each project. If you still
need help, you can contact me at [antfsmit@iu.edu](mailto:antfsmit@iu.edu).
Please provide as much information about the issues for either as you can.
